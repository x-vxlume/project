# project
This project is about a simple game of pong written with python with the help of various sources like youtube.


Basically a game of pong but you have two modes to choose from:

# The First Mode 
basically you against a computer

# The second Mode 
its you against a player 

both modes feature immersive and challenging gameplay and you get to pick the score.
